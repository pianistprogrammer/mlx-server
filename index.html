Features

Everything you need,
nothing you don't

Inspired by Ollama — MLX Server brings the same seamless local AI experience to Apple Silicon, powered by Apple's MLX framework for maximum performance on M-series chips.

Menu bar native

Lives quietly in your status bar. One click to open, no dock clutter, stays running in the background.

Chat interface

Clean, fast UI with full conversation history, markdown rendering, and code highlighting.

Download models

Pull any mlx-community model from Hugging Face directly inside the app — no terminal needed.

Instant startup

Chat window opens immediately on launch. Dependency checks run in the background without blocking you.

Vision models

Supports mlx-vlm for vision-language models — run Gemma, LLaVA and others with image understanding.

100% private

Everything runs on your device. No data is sent to the cloud, ever. Your conversations stay yours.
